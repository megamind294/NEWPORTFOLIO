# Rinkle Sharma — Developer Portfolio

Interactive multilingual portfolio for Rinkle Sharma, a software engineer and React developer based in Kraków, Poland.

## Highlights

- English, Polish, and Hindi interfaces
- Responsive desktop, tablet, and mobile layouts
- Interactive Three.js architecture scene
- Real project case studies with optimized visuals
- Downloadable résumé and direct contact links
- Static prerendering for Netlify and a Cloudflare Worker build for private review hosting

## Featured work

- **Carbon Warrior** — carbon-footprint monitoring and CO₂e analytics
- **Local AI Web Security Assistant** — privacy-first OWASP RAG workspace
- **Azure Maps Swipe** — interactive geospatial layer comparison

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run typecheck
npm run build
```

The Netlify publish directory is `dist/client`.
